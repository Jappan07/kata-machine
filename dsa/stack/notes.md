# Stack
A stack is a singly linked list where elements are added and removed only from the head,
following a Last-In-First-Out (LIFO) principle, similar to a stack of plates where the last item added is the first one removed.

head = top of stack
With a stack, only one end matters:
push at head
pop from head


when popping, we need to account for the case where the stack becomes empty so we need to point the tail to null too now
